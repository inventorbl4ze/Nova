# NOVA AI

A futuristic AI assistant with user accounts,
conversation history and an AI-powered chat interface.

## Features

- User registration and login
- Secure password hashing
- JWT authentication
- AI-powered conversations
- Conversation history
- PostgreSQL database
- Responsive mobile interface
- Dark futuristic design
- Copy AI responses

## Technology

- Node.js
- Express
- PostgreSQL
- HTML
- CSS
- JavaScript
- Render

## Requirements

- Node.js 20+
- PostgreSQL database
- AI provider API key

## Local installation

1. Clone this repository.
2. Install dependencies:

   npm install

3. Create a `.env` file using `.env.example`.
4. Add your database connection and AI provider credentials.
5. Start the application:

   npm start

6. Open http://localhost:3000

## Deployment

Deploy using the included render.yaml file.

Configure these environment variables:

- DATABASE_URL
- JWT_SECRET
- AI_BASE_URL
- AI_API_KEY
- AI_MODEL
- NODE_ENV=production

## Security

Never publish API keys, database passwords
or JWT secrets in your GitHub repository.
